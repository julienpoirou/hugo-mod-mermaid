# Security policy

## Reporting a vulnerability

Please **do not** open a public issue or disclose a suspected vulnerability before a fix is available. Report it privately to **julienpoirou@protonmail.com** with `[SECURITY]` in the subject.

Include:

- affected module version, OS, Hugo version, and browser when relevant;
- reproduction steps or a proof of concept;
- expected and actual behavior; and
- estimated impact and any known mitigations.

We acknowledge vulnerability reports within 72 hours, complete initial triage within 7 days, and provide either a remediation plan or a coordinated disclosure timeline within 30 days. We will coordinate public disclosure with the reporter after a fix or mitigation is available.

## Supported versions

The latest release and the preceding release receive security patches.
